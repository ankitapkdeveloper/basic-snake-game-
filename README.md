# Basic Snake Game

A simple Snake game built with HTML, CSS, and JavaScript.

## Files

- `index.html` - Main webpage
- `style.css` - Game styling
- `script.js` - Game logic

## Controls

### Desktop
Use:
- Arrow Up
- Arrow Down
- Arrow Left
- Arrow Right

### Mobile
- Use the on-screen buttons
- Swipe on the game board

## GitHub Pages Deployment

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.
7. Wait for GitHub Pages to publish your website.

Your game will then be available using the GitHub Pages link shown in the Pages settings.
